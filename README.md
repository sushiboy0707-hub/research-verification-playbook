# 竞对研究核实与审计 · 任务复现书

> 这是一个**方法论与任务说明书**仓库，不含任何内部资料、未公开数据或访谈原文。
> 目的是：把「如何核实一份研究报告」「如何审核一份竞品分析文档」这类工作的做法写清楚，
> 让任何人（包括 AI）可以拿同样的方法去处理自己的材料，并横向对比结果。

---

## 为什么会有这个仓库

竞对研究类的工作，产出物经常是「一份看起来很有道理的报告」。但报告里最常见的三类问题，恰好是最难自己发现的：

1. **引文与原文对不上**——写了引用编号，但原文里没有那句话，或者数字被改了。
2. **同一份文档内部打架**——摘要说 A，正文说 B，表格说 C。
3. **把推断写成了事实**——"大概率""主要因为"层层叠加，最后读者已经分不清哪些有出处、哪些是猜的。

这三类问题有共同点：**光靠读是查不出来的，必须回原文逐条核对。**

这个仓库记录的，就是「怎么查」的过程。

## 适用场景

- 手上有一份别人（或别的 AI）产出的研究报告，想知道它靠不靠谱
- 要审核一份团队内部的分析文档，找出矛盾和风险表述
- 想建立一套可复用的「引文溯源」工作习惯

---

## 核心原则（三句话）

> **每条结论都能回到原文。**
> **凡是标注「待核实」的，不要当成事实用；凡是会议口述，不要当成实测。**
> **凡是自己推出来的对称结构，先问一句：这个对称是真的存在，还是我编的。**
